# Risk register

Version: 1.1. Risks are identified, not accepted by the manager unless a linked decision states otherwise. Severity is qualitative exposure, not a measured probability.

| ID | Risk / exposure | Current treatment and trigger | Owner | Status / decision due |
|---|---|---|---|---|
| RISK-01 | Required cloud/Power BI access or host verification unavailable / high | Preflight records actual gaps; prove integration before full backend build; return to selection/design if infeasible | Agent; manager for access/route decision | Open / before dependent cloud implementation and initial Desktop proof |
| RISK-02 | Synthetic results overstate business value / high | Label claims, specify independent expected results, keep benefits hypothetical | Agent | Controlled by evidence rules; validate through Gates 5–9 |
| RISK-03 | GCP costs exceed available allowance or permissions exceed scope / high | DEC-SCOPE-001 supplies approximately $30/month allowance. Verify existing/shared usage, attribute project consumption and define bounded workload/retries/retention/cleanup at Gate 4; no assumed credits or enforced cap. Standing Pro and report publication excluded | Manager approves; agent implements | Open / before billable workloads |
| RISK-04 | Long-running session loses approval state / high | State index, gate source/version binding, conditions and affected-gate changes, workflow rehearsal | Agent | Verify during preparation and each resume |
| RISK-05 | Correlated criteria or convenient synthetic data distort selection / medium | Approved framework v1.0 retains value floor, readiness separation, sensitivity and no-build comparator; Gate 1 approval is not validation of candidate estimates | Agent applies approved model; manager reviews survivor/selection decisions | Open / Gates 2–3; model approved in DEC-G1-001 |
| RISK-06 | Governance cost overwhelms small MVP / medium | Few reusable templates, concise memos, only material ADRs, no workflow service | Agent | Monitor throughout; reduce redundant records |
