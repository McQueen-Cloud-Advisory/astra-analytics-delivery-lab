## Evidence procedure and gate coverage

For each execution, record QA ID and source requirement, command or precise human procedure, UTC/local timestamp, executor, source/configuration and fixture hashes, seed, host/tool version, expected result, actual result and status. Preserve failures alongside fixes/reruns and sanitize credentials, account identifiers where unnecessary, caches and unrelated diagnostics. Evidence may link to retained CI output; capture a durable summary if that output can expire. Use the [evidence template](../templates/evidence-and-acceptance.md).

| Decision boundary | Evidence needed; work still withheld |
|---|---|
| **Gate 5 — analytics baseline** | Approve material semantics, independent fixture expectations and this test plan. Before dependent cloud execution, retain actual Gate 4 authority and capability/limit condition closure; a plan or login is insufficient evidence. |
| **Gate 6 — platform** | QA-01..07 plus relevant QA-12/13 executed results, actual CI/security evidence and spend/resource summary. Minimal proof may contain a visual; final report development remains subject to Gates 6–7. |
| **Gate 7 — report design** | Decision-to-component mapping, planned filter/interaction/accessibility checks and any page-specific test detail, all fixed before observing the final implementation. Approval authorizes report completion. |
| **Gate 8 — readiness/release decision** | Required QA-08..13 results plus earlier platform evidence, runbook and exact release proposal. Identify Fail/Blocked/Not Run explicitly; “Ready” is only an agent recommendation. |
| **Gate 9 — final acceptance** | QA-14/15 outcomes, exact deployment and cleanup/retention status, remaining obligations and evidence-limited retrospective. If release was declined, record explicit undeployed scope rather than marking release checks passed. |

## Short demonstration and human host checks

Use the [implementation sequence](../plans/implementation-plan.md) and [existing Desktop procedure](../architecture/power-bi-integration.md). The manager supplies actual open/authenticate/import/render/interaction observations; agent-generated screenshots or static PBIP inspection do not replace them. Do not ask again for the already supplied Desktop version or treat a normal About screen as a failure.

Cover initial/subsequent/replay/correction and controlled failure/recovery with a small number of purposeful sessions inside the real attempt and cost limits. Use the approved simulated business dates to test aging and freshness boundaries without waiting weeks for cases to age. Real execution/refresh timestamps and any operational staleness checks still use actual observations. An observation period for the release is proposed and approved at Gate 8; it is limited to the checks needed for this short experiment, with no assumed 60-day dwell time or uptime SLA.

Before cleanup, retain the evidence needed to demonstrate what actually ran. If cleanup ends live refresh capability, state that plainly at handoff while preserving reproducible source and the last verified report artifact. Cloud project deletion or billing-account changes are outside ordinary table/dataset cleanup unless specifically authorized.

## Evidence limits and exceptions

Result states are **Pass**, **Fail**, **Not Run**, **Blocked**, and justified **N/A**; none is inferred from silence. An unmet required criterion triggers repair within bounds, an explicitly accepted permissible exception/scope change, or stopping. Do not lower a threshold after seeing a failure without the affected decision and retained original result.

Multiuser sharing, published-service refresh, supplier outreach and real-company adoption are outside scope. Row-level user separation may be N/A for this one-person synthetic lab with a recorded reason; correct effective cloud access and safe local artifacts still require QA-13. Large/stress-scale performance and production reliability remain unvalidated unless separately authorized and tested. The SCN-02 eight-hour/$19,200 opportunity and BH-02 remain hypotheses, even if every lab criterion passes.
